# 🧠 Профессиональный XMind Creator (Pro v3.0)

Инструмент для интеллектуальной визуализации архитектур, процессов и бизнес-стратегий. Генерирует `.xmind` файлы с поддержкой автоматического выбора структуры и семантического дизайна.

## 🚀 Новые возможности Pro v3

### ⚡ Интеллектуальный лейаут (`layout: "auto"`)
Если вы не знаете, какую структуру выбрать, укажите `"layout": "auto"`. Скрипт применит эвристики:
- **Радиальная**: Если у корня много детей (>4).
- **Таймлайн**: Если названия дочерних узлов начинаются с цифр (1., 2.).
- **Рыбья кость**: Если в заголовках есть слово "Cause" или "Причина".
- **Орг-схема**: Если в ветке более 8 элементов.

### 🧠 Генерация по шаблонам (`--template`)
Вы можете создавать готовые карты без JSON-файла:
- `--template swot`: Сильные/Слабые стороны, Возможности/Угрозы.
- `--template jtbd`: Jobs To Be Done (Situations, Motivations, Outcomes).
- `--template journey`: Карта пути пользователя (Awareness → Retention).

### 🎨 Семантические типы (`type`)
Добавьте поле `"type"` в узел для автоматической стилизации:
- `ai`: 🧠 + лейбл "AI/LLM"
- `db`: 🗄️ + лейбл "Database"
- `user`: 👤 + лейбл "User"
- `error`: ⚠️ + лейбл "Error"
- `task`: ✅ + лейбл "Task"
- `idea`: 💡 + лейбл "Idea"

## 🛠️ Спецификация JSON V3

```json
{
  "title": "Интеллектуальная Архитектура",
  "root": {
    "title": "🚀 Главный проект",
    "layout": "auto",
    "children": [
      { "title": "Модуль AI", "type": "ai" },
      { "title": "База данных", "type": "db" },
      { "title": "1. Начало процесса", "children": [...] }
    ]
  }
}
```

## 🚀 Использование CLI

### Генерация из шаблона
```powershell
python "scripts/create_xmind.py" --template swot --output "my_swot.xmind"
```

### Базовая команда (PowerShell)
```powershell
python "scripts/create_xmind.py" --input "data.json" --output "result.xmind"
```

## 📊 Поддерживаемые структуры (`layout`)
- `radial` / `map`: Классическая радиальная карта.
- `tree` / `tree_right`: Иерархическое дерево.
- `flow` / `logic_right`: Линейный процесс.
- `timeline`: Горизонтальная шкала.
- `fishbone`: Диаграмма Исикавы.
- `matrix`: Матрица/Таблица.
- `org_chart`: Сверху вниз.

## 🛡️ Безопасность и правила
- **Атомарность**: Запись через `.tmp` предотвращает повреждение файлов.
- **Авто-директории**: Папки создаются автоматически (`mkdir -p`).
- **Сохранение данных**: Входной JSON не удаляется по умолчанию.
