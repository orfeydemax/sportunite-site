# UI-анимация (UI Animation)

## Основные правила
- Анимируйте, чтобы прояснить причину/следствие или добавить продуманный восторг.
- Делайте взаимодействия быстрыми (200-300 мс; до 1 с только для иллюстративного движения).
- Никогда не анимируйте клавиатурные взаимодействия (навигация клавишами со стрелками, ответы на ярлыки, tab/фокус).
- Отдавайте предпочтение CSS; используйте WAAPI или JS только при необходимости.
- Делайте анимации прерываемыми и управляемыми пользовательским вводом.
- Уважайте настройку `prefers-reduced-motion` (уменьшайте или отключайте движение).

## Что анимировать
- Для перемещения и пространственных изменений анимируйте только `transform` и `opacity`.
- Для простой обратной связи по состоянию переходы `color`, `background-color` и `opacity` допустимы.
- Никогда не анимируйте свойства макета (layout properties); никогда не используйте `transition: all`.
- Избегайте анимации `filter` для основных взаимодействий; если это неизбежно, держите размытие (blur) <= 20px.
- SVG: применяйте трансформации к обертке `<g>` с использованием `transform-box: fill-box; transform-origin: center`.
- Отключайте переходы во время смены тем.

## Пространство и последовательность
- Устанавливайте `transform-origin` в точке срабатывания (trigger point).
- Для диалогов/меню начинайте примерно с `scale(0.85-0.9)`; избегайте `scale(0)`.
- Последовательное появление (staggering) делайте с задержкой <= 50 мс.

## Параметры сглаживания (Easing) по умолчанию
- Вход и hover на основе трансформаций: `cubic-bezier(0.22, 1, 0.36, 1)`.
- Движение: `cubic-bezier(0.25, 1, 0.5, 1)`.
- Простой hover цвета/фона/прозрачности: `200ms ease`.
- Избегайте `ease-in` для UI (кажется медленным).

## Доступность
- Если используется `transform`, отключите его при `prefers-reduced-motion`.
- Отключайте hover-переходы на сенсорных устройствах через `@media (hover: hover) and (pointer: fine)`.

## Производительность
- Ставьте на паузу зацикленные анимации за пределами экрана.
- Включайте `will-change` только во время интенсивного движения и только для `transform`/`opacity`.
- В библиотеках анимаций отдавайте предпочтение `transform` перед позиционными свойствами.
- Не анимируйте жесты перетаскивания (drag) с использованием переменных CSS.

## Референс
- Сниппеты и практические советы: [examples.md](examples.md)

## Рабочий процесс
1. Начните с основных правил, затем выберите подходящий сниппет из [examples.md](examples.md).
2. Сохраняйте движение функциональным; уважайте `prefers-reduced-motion`.
3. При ревью цитируйте пути к файлам и номера строк, предлагая конкретные исправления.
