# Исправление Линтинга и Форматирования

## Инструкции

1. Запустите `yarn prettier`, чтобы исправить форматирование
2. Запустите `yarn linc`, чтобы проверить наличие оставшихся проблем линтера
3. Сообщите о любых оставшихся исправлениях, требующих ручного вмешательства

## Распространенные Ошибки

- **Запуск prettier не на тех файлах** - `yarn prettier` форматирует только измененные файлы
- **Игнорирование ошибок linc** - Это приведет к сбою CI, исправьте их перед коммитом
