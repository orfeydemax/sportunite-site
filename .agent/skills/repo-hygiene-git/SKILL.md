# Repo Hygiene Git

Этот навык предоставляет утилиту CLI для автоматического "лечения" git-репозиториев.

## Когда использовать

* **Слишком много изменений**: Git показывает тысячи измененных файлов из-за того, что `node_modules` или `.venv` не игнорируются.
* **Секреты в репо**: Случайно закоммичен `.env` или ключи.
* **Отсутствует .gitignore**: В проекте нет файла игнорирования.
* **Проблемы с IDE**: VS Code тормозит из-за отслеживания тысяч сгенерированных файлов.

## Использование

Навык предоставляет CLI инструмент `repo-hygiene`.

### 1. Сканирование (Scan)

Проверить репозиторий на наличие проблем без внесения изменений:

```bash
node .agent/skills/repo-hygiene-git/index.js scan
```

### 2. Исправление (Fix)

Применить исправления:
1. Создать/обновить `.gitignore` (безопасно, добавляет блок правил).
2. Удалить мусорные файлы из индекса git (`git rm --cached`), оставляя их на диске.

```bash
# Простой запуск (с подтверждением)
node .agent/skills/repo-hygiene-git/index.js fix

# Автоматически (без вопросов)
node .agent/skills/repo-hygiene-git/index.js fix --yes

# С созданием коммита
node .agent/skills/repo-hygiene-git/index.js fix --yes --commit
```

### 3. Опции

* `--root <path>`: Указать путь к корню репозитория (по умолчанию текущая папка).
* `--dry-run`: Показать, что будет сделано, но не выполнять команды.
* `--policy <name>`: Набор правил игнорирования (по умолчанию `fullstack`).

## Правила игнорирования (Fullstack)

Навык по умолчанию добавляет правила для:
* **Node.js**: `node_modules`, `dist`, `.next`, `.vite`, логи.
* **Python**: `.venv`, `__pycache__`, `*.pyc`.
* **System**: `.DS_Store`, `Thumbs.db`, `.vscode/`, `.idea/`.
* **Secrets**: `.env`, `*.pem`, `*.key`.

## Устранение неполадок

Если инструмент удалил что-то лишнее из индекса (файлы остались на диске, но помечены как deleted в git):
1. `git restore --staged <file>` — вернуть файл в индекс.
2. `git reset` — сбросить все изменения индекса, если еще не закоммичено.
