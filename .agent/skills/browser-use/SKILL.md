# Навык Browser Use

Этот навык позволяет вам управлять браузером для выполнения различных задач. Он использует Python-библиотеку `browser-use` и Playwright.

## Установка

Перед первым использованием этого навыка необходимо запустить скрипт установки, чтобы установить необходимые зависимости (`browser-use`, `playwright` и браузеры).

```bash
python .agent/skills/browser-use/scripts/setup.py
```

## Использование

### Простоя выполнение задач

Для запуска задачи в браузере используйте скрипт `run_browser_task.py`. Этот скрипт принимает описание задачи и URL.

```bash
python .agent/skills/browser-use/scripts/run_browser_task.py --url "https://example.com" --task "Ваше описание задачи здесь"
```

**Параметры:**

- `--url`: Начальный URL для браузера.
- `--task`: Описание того, что вы хотите, чтобы агент сделал (на естественном языке).
- `--headless`: (Опционально) Запуск в безголовом режиме (по умолчанию: False/С интерфейсом).
- `--api-key`: (Опционально) API-ключ LLM, если требуется базовым агентом (обычно настраивается через переменные окружения).

**Пример:**

```bash
# Извлечь главный заголовок со страницы
python .agent/skills/browser-use/scripts/run_browser_task.py --url "https://news.ycombinator.com" --task "Получи заголовок главной новости"
```

### Продвинутое использование (Python)

Вы также можете импортировать и использовать библиотеку напрямую в своих Python-скриптах, если вам нужен больший контроль или интеграция.

```python
from browser_use import Agent
import asyncio

async def main():
    agent = Agent(
        task="Найди билет в одну сторону из Бали в Оман на 12 января 2025 года, верни мне самый дешевый вариант.",
        llm=... # Настройте вашу LLM здесь
    )
    result = await agent.run()
    print(result)

asyncio.run(main())
```

## Устранение неполадок

- **Подробные логи**: Если скрипт завершается ошибкой, проверьте логи. Возможно, вам потребуется установить недостающие системные зависимости для Playwright.
- **Браузер не найден**: Убедитесь, что вы запустили `playwright install` (обрабатывается скриптом `setup.py`).
