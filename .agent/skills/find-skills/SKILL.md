# Поиск Навыков (find-skills)

Этот навык помогает вам находить и устанавливать навыки из открытой экосистемы навыков агентов, используя CLI `npx skills`.

## Когда использовать этот навык
Используйте этот навык, когда пользователь:
- Спрашивает "как мне сделать X", где X может быть обычной задачей, для которой вероятно существует навык.
- Говорит "найди навык для X" или "есть ли навык для X".
- Спрашивает "можешь ли ты сделать X", где X — это специализированная возможность.
- Выражает интерес к расширению возможностей агента.
- Хочет найти инструменты, шаблоны или рабочие процессы.
- Упоминает, что хотел бы помощи в конкретной области (дизайн, тестирование, развертывание и т.д.).

## Как помочь пользователям найти навыки

### Шаг 1: Поймите, что им нужно
Когда пользователь просит помощи с чем-то, определите:
1. Домен (например, React, тестирование, дизайн, развертывание).
2. Конкретную задачу (например, написание тестов, создание анимаций, проверка PR).
3. Является ли это достаточно распространенной задачей, для которой вероятно существует навык.

### Шаг 2: Поиск навыков
Запустите команду `npx skills find` с соответствующим запросом.

```bash
npx -y skills find [запрос]
```

Примеры:
- Пользователь спрашивает "как мне ускорить мое React приложение?":
  `npx -y skills find react performance`
- Пользователь спрашивает "можешь помочь мне с проверкой PR?":
  `npx -y skills find pr review`
- Пользователь спрашивает "мне нужно создать чейнджлог":
  `npx -y skills find changelog`

Команда вернет результаты вроде:
```
Install with npx skills add <owner/repo@skill> vercel-labs/agent-skills@vercel-react-best-practices └ https://skills.sh/vercel-labs/agent-skills/vercel-react-best-practices
```

### Шаг 3: Представьте варианты пользователю
Когда вы найдете релевантные навыки, представьте их пользователю с:
1. Именем навыка и тем, что он делает.
2. Командой установки, которую они могут запустить.
3. Ссылкой для изучения подробностей на `skills.sh`.

Пример ответа:
> Я нашел навык, который может помочь! Навык "vercel-react-best-practices" предоставляет рекомендации по оптимизации производительности React и Next.js от инженеров Vercel. Чтобы установить его: `npx skills add vercel-labs/agent-skills@vercel-react-best-practices`
> Узнать больше: https://skills.sh/vercel-labs/agent-skills/vercel-react-best-practices

### Шаг 4: Предложите установить
Если пользователь хочет продолжить, вы можете установить навык для него:

```bash
npx -y skills add <owner/repo@skill>
```
Используйте флаг `-g` для глобальной установки, если это запрошено, или опустите его для локальной установки. Флаг `-y` пропускает запросы подтверждения.

## Общие категории навыков
При поиске учитывайте эти общие категории:
- development (разработка)
- testing (тестирование)
- deployment (развертывание)
- efficiency (эффективность)
- design (дизайн)
- documentation (документация)

## Советы для эффективного поиска
1. **Используйте конкретные ключевые слова**: "react testing" лучше, чем просто "testing".
2. **Пробуйте альтернативные термины**: Если "deploy" не работает, попробуйте "deployment" или "ci-cd".
3. **Проверяйте популярные источники**: Многие навыки поступают от `vercel-labs/agent-skills` или `ComposioHQ/awesome-claude-skills`.

## Когда навыки не найдены
Если релевантных навыков не существует:
1. Подтвердите, что существующий навык не найден.
2. Предложите помочь с задачей напрямую, используя ваши общие возможности.
3. Предложите пользователю создать свой собственный навык с помощью `npx -y skills init`.

Пример:
> Я искал навыки, связанные с "xyz", но не нашел совпадений. Я все еще могу помочь вам с этой задачей напрямую! Хотите, чтобы я продолжил? Если это то, что вы делаете часто, вы можете создать свой собственный навык: `npx skills init my-xyz-skill`
