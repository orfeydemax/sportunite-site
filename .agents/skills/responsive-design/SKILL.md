# Адаптивный дизайн (Responsive Design)

Освойте современные техники адаптивного дизайна для создания интерфейсов, которые плавно подстраиваются под любые размеры экранов и контексты устройств.

## Когда использовать этот навык

- Реализация адаптивных макетов по стратегии mobile-first
- Использование контейнерных запросов (container queries) для адаптивности компонентов
- Создание плавной типографику и систем отступов
- Построение сложных макетов с помощью CSS Grid и Flexbox
- Разработка стратегий контрольных точек (breakpoints) для дизайн-систем
- Реализация адаптивных изображений и медиафайлов
- Создание паттернов адаптивной навигации
- Построение адаптивных таблиц и отображений данных

## Основные возможности

### 1. Контейнерные запросы (Container Queries)

- Адаптивность на уровне компонентов независимо от вьюпорта
- Единицы измерения контейнерных запросов (cqi, cqw, cqh)
- Запросы стилей (style queries) для условной стилизации
- Фолбэки для поддержки браузеров

### 2. Плавная типографика и отступы

- CSS clamp() для плавного масштабирования
- Единицы вьюпорта (vw, vh, dvh)
- Плавные шкалы шрифтов с ограничениями min/max
- Адаптивные системы отступов

### 3. Паттерны макетов

- CSS Grid для двумерных макетов
- Flexbox для одномерного распределения
- Внутренние макеты (intrinsic layouts — на основе контента)
- Subgrid для выравнивания вложенных сеток

### 4. Стратегия контрольных точек (Breakpoint Strategy)

- Медиа-запросы по принципу mobile-first
- Контрольные точки на основе контента
- Интеграция дизайн-токенов
- Проверка возможностей через @supports (feature queries)

## Краткий справочник

### Современная шкала контрольных точек

```css
/* Mobile-first контрольные точки */
/* База: Мобильные устройства (< 640px) */
@media (min-width: 640px) {
  /* sm: Телефоны в ландшафте, маленькие планшеты */
}
@media (min-width: 768px) {
  /* md: Планшеты */
}
@media (min-width: 1024px) {
  /* lg: Ноутбуки, небольшие десктопы */
}
@media (min-width: 1280px) {
  /* xl: Десктопы */
}
@media (min-width: 1536px) {
  /* 2xl: Большие десктопы */
}
```

## Ключевые паттерны

### Паттерн 1: Контейнерные запросы

```css
/* Определяем контекст контейнера */
.card-container {
  container-type: inline-size;
  container-name: card;
}

/* Запрос к контейнеру, а не к вьюпорту */
@container card (min-width: 400px) {
  .card {
    display: grid;
    grid-template-columns: 200px 1fr;
    gap: 1rem;
  }
}
```

### Паттерн 2: Плавная типографика

```css
/* Плавная шкала через clamp() */
:root {
  /* Мин. размер, предпочтительный (плавный), макс. размер */
  --text-base: clamp(1rem, 0.9rem + 0.5vw, 1.125rem);
  --text-2xl: clamp(1.5rem, 1.25rem + 1.25vw, 2rem);
}
```

### Паттерн 3: Адаптивный CSS Grid

```css
/* Сетка с авто-подгонкой — элементы переносятся автоматически */
.grid-auto {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(300px, 100%), 1fr));
  gap: 1.5rem;
}
```

## Лучшие практики

1. **Mobile-First**: Начинайте со стилей для мобильных, улучшайте для больших экранов.
2. **Контрольные точки по контенту**: Устанавливайте точки там, где "ломается" контент, а не под конкретные устройства.
3. **Гибкость вместо фиксации**: Используйте плавные значения (fluid) для шрифтов и отступов.
4. **Контейнерные запросы**: Используйте для адаптивности на уровне компонентов.
5. **Тест на реальных устройствах**: Эмуляторы не всегда показывают реальную картину.
6. **Производительность**: Оптимизируйте изображения, используйте lazy load.
7. **Области касания**: Минимум 44x44px для мобильных кнопок.

## Общие проблемы

- **Горизонтальная прокрутка**: Контент вылазит за пределы вьюпорта.
- **Фиксированная ширина**: Использование px вместо относительных единиц.
- **Высота вьюпорта**: Проблемы со 100vh в мобильных браузерах (решение: use dvh).
- **Размер шрифта**: Текст слишком мелкий на мобильных.
- **Цели касания**: Кнопки слишком маленькие для точного нажатия.
- **Соотношение сторон**: Искажение или растягивание изображений.
