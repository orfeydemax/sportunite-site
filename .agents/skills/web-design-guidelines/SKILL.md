# Web Interface Guidelines (Руководство по веб-интерфейсам)

Проверка файлов на соответствие Руководству по веб-интерфейсам.

## Как это работает

1. Получает последние рекомендации по URL-адресу источника ниже.
2. Читает указанные файлы (или запрашивает у пользователя файлы/шаблон).
3. Проверяет на соответствие всем правилам в полученных рекомендациях.
4. Выдает результаты в кратком формате `file:line`.

## Источник рекомендаций

Получайте свежие рекомендации перед каждой проверкой:

```
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md
```

Используйте WebFetch для получения последних правил. Полученный контент содержит все правила и инструкции по формату вывода.

## Использование

Когда пользователь предоставляет аргумент в виде файла или шаблона:
1. Получите рекомендации по URL-адресу источника выше.
2. Прочитайте указанные файлы.
3. Примените все правила из полученных рекомендаций.
4. Выведите результаты, используя формат, указанный в рекомендациях.

Если файлы не указаны, спросите пользователя, какие файлы нужно проверить.
